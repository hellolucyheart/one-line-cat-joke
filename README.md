One joke about cats, one line, under 200 characters. A laser pointer bought to tire the cat out ends up tiring the owner out instead — the hunter becomes the hunted, panting on the floor at midnight.

## Run it

```sh
python3 main.py
```

It validates the line (one sentence, 1–200 characters, no line breaks) and writes it to `/output/entry.txt`.
